# 모바일 청첩장 (GitHub Pages) 설계

## 목표
참고: https://www.areum.co.kr/invitation/basic-1 구성을 따른 모바일 청첩장을 `seonghyunsun.github.io`에 정적 사이트로 배포한다. 공지사항 항목에는 **참석 여부 전달만** 둔다.

## 확정 정보
| 항목 | 값 |
|---|---|
| 신랑 | 김민혁 |
| 신부 | 성현선 |
| 일시 | 2027-01-03 (일) 오후 12:40 |
| 장소 | 루이비스컨벤션 송파문정점 B1층 |
| 주소 | 서울특별시 송파구 법원로9길 26 H비즈니스파크 D동 |

미정(샘플 값으로 채우고 `config.js`에서 교체): 부모님 성함, 연락처, 계좌번호, 사진, 인사말, 교통편 안내.

## 접근
순수 HTML/CSS/JS, 빌드 없음. 저장소 루트 `index.html`을 GitHub Pages가 그대로 배포한다.

## 구조
```
index.html
css/style.css        # 모바일 우선, 최대 폭 480px 중앙 정렬
js/config.js         # 모든 개인 정보와 RSVP 웹앱 URL
js/main.js           # 카운트다운, 달력, 갤러리, 계좌 복사, 스크롤 등장 효과
js/rsvp.js           # 참석 폼 제출
images/
apps-script/Code.gs  # 시트에 응답을 추가하는 스크립트(배포용 보관)
```

## 섹션 순서
1. 표지: SAVE THE DATE, 사진, 이름, 일시, 장소
2. 모시는 말씀, 양가 부모님 소개, 연락하기(전화·문자)
3. 달력과 D-day: JS로 달력 생성, 예식일 강조, 카운트다운
4. 갤러리: 썸네일 그리드, 라이트박스
5. 오시는 길: 주소 복사, 카카오맵·네이버지도·티맵 링크, 교통편
6. 공지사항: 참석 여부 전달 버튼 → 모달 폼(이름, 참석/불참, 인원, 식사 여부, 전할 말)
7. 마음 전하실 곳: 신랑측·신부측 아코디언, 계좌 복사
8. 푸터: 카카오톡 공유, 링크 복사

## RSVP 데이터 흐름
- 폼 제출 → `fetch`로 Apps Script 웹앱 URL에 POST → 시트에 한 행 추가.
- 성공·실패 메시지 표시, 제출 중 버튼 비활성화로 중복 제출 방지.
- 시트 생성과 웹앱 배포는 사용자가 수행한다. 배포 절차는 README에 안내한다.
- 웹앱 URL이 비어 있으면 폼은 제출 불가 상태로 안내 메시지를 보인다.

## 오류 처리
- 필수 입력(이름, 참석 여부) 검증.
- 네트워크 실패 시 재시도 안내.
- 클립보드 API 미지원 시 선택 가능한 텍스트로 대체.

## 테스트
- 로컬 서버에서 모바일 폭(375px 전후)으로 직접 확인.
- 달력·D-day 계산은 순수 함수로 분리해 2027-01-03이 일요일로 표시되는지, 남은 일수가 맞는지 점검.
